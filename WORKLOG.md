# Web App Template — Feature List

Atomic feature breakdown for project estimation, one estimable unit per row — the same format as `template-backend/WORKLOG.md`. Every feature lands here in the same commit that implements it; the list never lags behind the code.

> ✅ The auth flow is covered by unit/component tests (Vitest + React Testing Library) and browser e2e tests (Playwright against an in-browser API fake). Every new feature ships with its tests in the same commit.

## Implemented

| #   | Feature                                 | Notes                                                                                                                                                                                                                                                    |
| --- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Web App: Project scaffolding            | Next.js 16, React 19, strict TypeScript, Tailwind CSS 4; dev/prod on port 3001                                                                                                                                                                           |
| 2   | Web App: Code quality tooling           | ESLint (Next preset) + Prettier + husky/lint-staged pre-commit hook; typecheck script                                                                                                                                                                    |
| 3   | Web App: Engineering guidelines         | CLAUDE.md: code style, constants, routing & auth rules                                                                                                                                                                                                   |
| 4   | Web App: Routing skeleton               | Route groups (auth)/(app) with separate layouts; ROUTES constants (no hard-coded paths); / redirects to /dashboard; not-found page                                                                                                                       |
| 5   | Web App: App shell layout               | Sidebar + Header for the (app) group; centered card layout for (auth)                                                                                                                                                                                    |
| 6   | Web App: Auth: Login page               | LoginForm against POST /auth/sign-in, error display, redirect to a validated next path                                                                                                                                                                   |
| 7   | Web App: Auth: Token storage            | Classic bearer: both JWTs in localStorage (shared across tabs), try/catch-safe; expired tokens replaced via the refresh flow                                                                                                                             |
| 8   | Web App: Auth: API client               | axios instance; request interceptor adds the bearer header, response interceptor does a single shared refresh on 401, one retry, session cleanup + onUnauthorized on a second 401 and maps HTTP errors to ApiError; skipAuth for token-issuing endpoints |

| 11  | Web App: Auth: Open-redirect protection | next query param validated to same-origin absolute paths (getSafeNextPath)                                                                                                                                                                               |
| 12  | Web App: Env configuration              | .env.example / .env.local with API_URL                                                                                                                                                                                                                   |
| 13  | Web App: Feature worklog                | This document; every portion updates it in the same commit (rule in CLAUDE.md)                                                                                                                                                                           |
| 14  | Web App: Auth: Multi-tab refresh lock   | navigator.locks + token re-check: parallel tabs cannot redeem the same refresh token and trip the backend's reuse detection; in-memory fallback where Web Locks is unavailable                                                                           |
| 15  | Web App: Test setup                     | Vitest + React Testing Library + jsdom; `npm test` / `test:watch` / `test:cov`; in-memory axios adapter helper (`src/test/axiosMock.ts`) for end-to-end apiClient tests                                                                                  |
| 16  | Web App: Auth: Unit/component tests     | apiClient (bearer, refresh + retry, second 401, failed refresh, skipAuth, error mapping, network error, cross-tab lock), tokenStorage, auth.utils, useAuthStore, AuthGuard, GuestGuard, LoginForm                                                        |
| 17  | Web App: Component structure convention | CLAUDE.md rule: folder per component with `Component.tsx` + `useComponent.ts` (logic hook) + optional `.styles.ts` + `index.ts`; LoginForm, AuthGuard, GuestGuard refactored to it                                                                       |
| 18  | Web App: E2e tests                      | Playwright + in-browser API fake (`e2e/apiMock.ts`): sign-in, wrong credentials, guest redirect, deep-link return, external `next` rejected, refresh on expiry, revoked session, cross-tab single refresh, sign-out; `npm run test:e2e`                  |
| 19  | Web App: Auth: Logout flow              | Header sign-out button → POST /auth/logout + store/storage cleanup; AuthGuard performs the redirect; covered by unit + e2e tests                                                                                                                         |
