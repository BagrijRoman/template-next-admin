# Web App Template — Feature List

Atomic feature breakdown for project estimation, one estimable unit per row — the same format as `template-backend/WORKLOG.md`. Every feature lands here in the same commit that implements it; the list never lags behind the code. Tests are work too: every feature with tests is followed by its own `Tests: <feature>` row stating the test type (unit / component / e2e) and what is covered.
