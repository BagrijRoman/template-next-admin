# template-next-web

Starter template for admin panel web frontends.

**Stack:** Next.js, React, Tailwind CSS, React Query, Zustand.

## Getting started with a new project

1. Clone this template into a new repo.
2. Update `name` and `description` in `package.json`.
3. Set up `.env` (API URL, ports).
4. Replace this README with the project's own.
